## Live repository panel

The website uses GitHub's public repository metadata endpoint when available:
`GET https://api.github.com/users/jebashajida/repos`.

This separate panel can show newer repositories without modifying the curated
CV cards. Returned descriptions are displayed as text; website links come
from each repository's homepage field and are not independently availability
checked. Public API reads can be rate-limited; the static fallback remains.
The optional build-time sync script keeps credentials out of browser assets.
